# 校园工具箱 Campus Toolbox

> 一个面向高校学生的在线工具集合。浏览器打开就能用，数据不离开你的电脑，断网也能用。

## 这是什么

校园工具箱把学生在校期间真正每天会用到的小工具集中到一个网页里，打开即用，不用装 App、不用注册账号、不用把作业和公文传到别人的服务器上。

它基于优秀的开源项目 [it-tools](https://github.com/CorentinTh/it-tools)（GPL-3.0）二次开发，保留了原项目 90 个经过大量用户验证的实用工具，并在此基础上：

- **新增原创工具**，解决 it-tools 没有覆盖的校园场景
- **界面全面中文化**，术语按国内高校习惯改写
- **可离线使用**，校园网不稳定时照样能开
- **所有处理在本地完成**，不上传任何文档内容

## 原创工具

### 1. 公文格式自检（`/official-document-checker`）

**解决的问题**：学生社团、班级、学生会每学期都要发通知、写策划、报材料。格式不合规会被退回重写，但大部分人并不知道自己错在哪 —— 是字号不对，还是序号写成了「1.」而不是「1．」，还是成文日期没写汉字。

**它怎么做得更好**：

| 同类网页工具 | 校园工具箱 |
|---|---|
| 只提供规范条文让你自己比对 | 自动读文档、自动判违规、给出格式得分 |
| 只支持粘贴文本 | 支持上传 `.docx`，**直接读取文档内部的真实字体、字号、行距、页边距** |
| 只告诉你有问题 | 定位到具体段号、高亮原文片段、给出 Word 里的操作步骤 |
| 发现问题后要自己改 | 文本类问题可**一键修复**，并给出修复前后对照 |
| 把文档上传到服务器处理 | 全部在浏览器本地解析，文件不出设备 |
| 没有留痕 | 一键导出 Markdown 检查报告，可附在材料里 |

检查依据 **GB/T 9704-2012《党政机关公文格式》**，覆盖 14 条规则、8 个类别：

- 页面设置：页边距（上 37 mm、左 28 mm）
- 字体字号：标题方正小标宋 2 号、正文仿宋_GB2312 3 号、一级标题黑体、二级标题楷体
- 段落格式：行距 28 磅、首行缩进 2 字符
- 版头：发文字号六角括号、不写「第」、不编虚位
- 层级序号：一、→（一）→ 1．→（1）四级规范
- 成文日期：汉字数字、「〇」不写「零」
- 附件说明、标点符号、用语规范

### 2. 课表冲突检测与空闲时段（`/timetable-conflict-checker`）

**解决的问题**：教务处系统只告诉你「这门课在哪」，不会告诉你「两门课撞了」；排社团例会、约小组讨论时，也没人愿意手动比对四个人的课表。

**功能**：

- **冲突检测**：区分「时间完全重叠」与「部分重叠」，给出重叠分钟数
- **空闲时段计算**：在设定的作息范围内自动算出所有空闲区间，可过滤碎片时间
- **多人求交集**：录入多人的课表，直接算出「所有人都空闲」的时段，并推荐最长的那一段
- **课表可视化**：时间轴热力展示，一眼看出哪天最忙
- **排课建议**：自动指出课业最重的一天，建议不要把例会安排在那天

支持直接粘贴教务系统的课表文本，兼容 `周一 08:00-09:40 高等数学 教三201` 和 `周三 3-4节 线性代数` 两种写法。

## 中文本地化

原项目已提供简体中文语言包，本项目在此基础上做了进一步工作：

- 新增工具的名称、描述、关键词全部按中文使用习惯撰写，**中文和拼音关键词都能搜到**（例如搜「公文」「gongwen」「发文字号」都能命中）
- 新增「校园常用」分类，把学生高频工具放在首页最前面
- 界面文案按国内高校语境调整（「教务」「社团」「例会」等）

## 离线可用

学校机房、图书馆、教学楼某些角落的网很不稳定，所以离线能力是硬需求：

- 配置了 PWA，首次访问后可安装到桌面，之后**断网也能打开**
- 静态资源由 Service Worker 缓存，二次访问秒开
- 所有工具**纯前端运算**，不发任何网络请求，因此离线时功能完全不打折
- 公文解析、课表计算、格式校验都在浏览器内完成

## 本地运行

需要 Node.js 18+ 与 pnpm：

```bash
pnpm install
pnpm dev          # 开发服务器，默认 http://localhost:5173
pnpm build        # 构建产物到 dist/
pnpm preview      # 预览构建结果
pnpm test:unit    # 单元测试
```

使用 Docker：

```bash
docker build -t campus-toolbox .
docker run -p 8080:80 campus-toolbox
```

## 如何新增一个工具

项目结构是「一个工具 = 一个目录」，加工具门槛很低：

```
src/tools/
└── your-tool/
    ├── index.ts          # 工具注册信息（名称、路径、描述、关键词、图标）
    ├── your-tool.vue     # 工具界面
    └── your-tool.models.ts  # （可选）纯逻辑，便于写单元测试
```

然后在 `src/tools/index.ts` 里 import 并加入对应分类的 `components` 数组即可。

或者直接用脚手架：

```bash
pnpm script:create:tool
```
